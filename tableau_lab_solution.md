# Tableau Lab - Customer Segmentation
By: Paulina Mamiaga
---------------

## 📊 Overview
This project analyzes customer segmentation based on:
- Gender
- Employment Status
- Marital Status
- Geographic Distribution
----------------------------------
## 🔍 Key Insights
- Customer base is concentrated in employed and married segments
- No significant gender imbalance
- Key states: California, Oregon, Arizona
